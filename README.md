# oridanieli.com

A plain static memorial site for Uri Danieli — just `index.html` plus the `images/` folder, served by GitHub Pages. No build step, no dependencies.

To add a story, add an entry to the `stories` array in `index.html`. To add an image, drop the file into `images/` and reference it from that entry's `img` field (e.g. `img:"images/my-photo.jpg"`).
